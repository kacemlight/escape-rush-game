# Escape Rush 🎮

A 2D browser game where you dodge obstacles and race to the finish line.

## How to Play
- **Desktop:** Arrow keys / WASD to move, Up / Space to jump
- **Mobile:** On-screen Left, Jump, Right buttons

## Tech
- Pure HTML5 Canvas + CSS + JavaScript
- Single self-contained `index.html` — no build step, no dependencies
- Works offline (except Google Font)

## Live Play
Open `index.html` in any modern browser and play immediately.

## Levels
1. **The Warm-Up** — slow obstacles, generous gaps
2. **Picking Up Speed** — medium speed, tighter corridors
3. **Full Sprint** — fast obstacles, tight timing required

Can you make it out alive?
